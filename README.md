Retail Supply Chain & Inventory Risk Analytics


Project Overview

This project focuses on analyzing retail supply chain and inventory data to identify stock risks and improve inventory management using data analytics.


Objectives

Analyze inventory levels and stock availability.
Identify stockout and overstock risks.
Monitor supply chain performance.
Support data-driven business decisions.


Tools & Technologies

SQL
Python
Power BI


Key Features

Inventory risk analysis
Stock availability monitoring
Supply chain performance analysis
Business intelligence and reporting


Project Structure

Project datasets, SQL queries, Python scripts, and Power BI reports are organized into relevant folders as applicable.
